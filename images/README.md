# Thư mục Hình Ảnh (Images)

Thư mục này dùng để chứa tất cả các hình ảnh của website Quán Hủ Tiếu Nam Vang.

## Các loại hình ảnh khuyên dùng:

1. **Hình ảnh món ăn (`images/dishes/` hoặc `images/`)**:
   - `hu-tieu-nam-vang-nuoc.jpg` : Hủ tiếu nước đặc biệt
   - `hu-tieu-nam-vang-kho.jpg` : Hủ tiếu khô sốt gia truyền
   - `hu-tieu-muc-tom.jpg` : Hủ tiếu hải sản tôm mực
   - `hu-tieu-xi-quach.jpg` : Hủ tiếu xí quách xương ống
   - `banh-canh-gio-heo.jpg` : Bánh canh giò heo
   - `nuoc-mia-sam.jpg` : Nước sâm rong biển / Nước sâm mía lau
   - *Kích thước khuyến nghị*: 800x600px hoặc tỷ lệ 4:3, định dạng JPG/PNG/WebP rõ nét, dung lượng < 500KB để web tải nhanh.

2. **Hình ảnh Banner / Không gian quán (`images/banner/`, `images/gallery/`)**:
   - `hero-banner.jpg` : Ảnh banner chính đầu trang (1920x800px)
   - `about-story.jpg` : Ảnh nồi nước dùng hoặc đầu bếp (1000x800px)
   - `gallery-1.jpg` đến `gallery-6.jpg` : Ảnh không gian quán, khách ăn đông vui

3. **Logo & Biểu tượng**:
   - `logo.png` : Logo thương hiệu nền trong suốt (PNG hoặc SVG)

---
*Mặc định website đã tích hợp sẵn các hình ảnh món ăn minh họa chất lượng cao để hiển thị đẹp ngay lập tức. Khi bạn thêm ảnh vào thư mục này, chỉ cần mở file `js/data.js` hoặc `index.html` để cập nhật đường dẫn ảnh tương ứng.*
